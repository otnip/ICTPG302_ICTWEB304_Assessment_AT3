This is a sample website used both to learn how to develop a website and to provide resources to outhers to learn web development skills.
The focus here is on Hyper Text Markup Language (HTML), Cascading Style Sheets (CSS) and JavaScript.
A future project includes researching React and combinging the website with a mySQL backend. 

When I last worked on web devlopment, I had access to a full SQL database and we used ASP, JavaScript and HTML. We had a separate person to develp the User Interface (UI)

All links that point to external sites should open in separate tabs. Only the menu links between pages are set up to open in the same tab.
