All about style sheets

This page includes basic steps on how to use style sheets to set the design elements of your web pages.

Home About Style sheets for web pages

Style sheets are a great way to set the style elements such as font and colours accross all your web pages.
By putting all of these style elements in one place, you can update your entire website by updating one style sheet!

How do I create a style sheet?
A style sheet is a text file which has a .css file extention. CSS stands for Cascading Style Sheets because if you set an aspect of one element, such as colour, this can then be applied to it's children elements unless other options are applied.
Style elements are can also be insteted into the web page itself, but then will not be available to other pages.

Google is an example of a popular site which uses inline CSS. According to Google, this is because they are a high traffic site and inline CSS allows pages to load almost instantly as there is no need to make a connection to a separate page for details on how to display the page. You can see these style elements yourself by opening a google page and using the shotcut Ctrl+U which will open the html (page source) in a new tab.
You can also see the details by saving the web page to your computer and then opening it in an text editor.
