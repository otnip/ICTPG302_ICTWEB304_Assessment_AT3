Get started with web pages - what you need.

  1. Text editor, I recommend Notepad ++
  2. Web browser such as Chrome, Edge or Firefox in which to view your new web page
  3. Time and patience. Things will go wrong, but if you are methodical and patient, you can work it out.
  4. A good beginner guide such as:
    • W3 Schools - Free coding lessons including html, javascript for web development
    • Find your favourite YouTub Channel, here are a couple or examples:
      • HTML & CSS Full Course for Free
      • Learn HTML - Full Tutorial for Beginners
    • Free AI "Tutor" for example, ask chatgpt "how to I get started with web development."
      Yes, you can have chatgpt do it all for you, but what will you learn from that as a beginner?
      Save that for later once you know how it all works
  5. A sense of humour and hopefuly you will have some fun along the way.
